# Frontières du vivant
Monde indépendant de JDR scientifique, préparé pour deux joueurs et un MJ.

Lancement : `node serveur/serveur.js 3204 --monde frontieres-du-vivant`.
Sélection des scripts PowerShell : `$env:CONSEIL_MONDE = 'frontieres-du-vivant'`.

Règles : manuel.md. Dossier initial : recherche/dossier.md. Le corpus est vide ; aucun tour biologique n'a été joué. Le moteur conserve son interface commune ; le registre scientifique est documentaire, sans moteur de validation bibliographique automatique.
