# Lumina Prime — 2042

Paquet de monde créé pour la partie de gestion urbaine et architecture.

Lire [le cadre](canon/cadre.md), [le conseil](canon/conseil.md) et [le manuel](manuel.md).

Lancer depuis la racine du dépôt : `node serveur/serveur.js 3197 --monde lumina-prime`.
Ouvrir http://localhost:3197/bascule?vers=nova pour prendre le siège de Nova.

Le paquet contient l’état initial et un plan schématique. Aucune scène de PNJ n’a été jouée, aucune disparition appliquée. L’échéance de J3 exige un arbitrage du MJ ; aucun algorithme de disparition automatique n’est ajouté.
